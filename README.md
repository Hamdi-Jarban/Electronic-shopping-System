# نظام التسوق الإلكتروني

**وصف المشروع**

نظام التسوق الإلكتروني هو تطبيق ويب مبني باستخدام Laravel، يتيح للزوار استعراض المنتجات والاطلاع على تفاصيلها، كما يوفّر للعميل إمكانية إضافة المنتجات إلى سلة التسوق وإتمام الطلب. ويضم النظام لوحة إدارة لإدارة المنتجات، محمية بتسجيل الدخول والصلاحيات.

## أهداف المشروع

- توفير واجهة إلكترونية لعرض المنتجات وتفاصيلها.
- تمكين العملاء من إضافة المنتجات إلى السلة وإرسال طلب الشراء.
- إتاحة إدارة المنتجات للمستخدمين المخوّلين.
- تنظيم بيانات المتجر، مثل المنتجات والتصنيفات والعلامات التجارية والمخزون والطلبات.
- توفير بنية قابلة للتطوير وإضافة وظائف جديدة مستقبلًا.

## الوظائف الرئيسية

**واجهة العميل:** عرض المنتجات وتفاصيلها، وإدارة سلة التسوق، وإتمام الطلب، بالإضافة إلى وظائف التسجيل وتسجيل الدخول وإدارة الملف الشخصي.

**لوحة الإدارة:** عرض المنتجات وإضافة منتجات جديدة. يتطلب الوصول إلى لوحة الإدارة تسجيل الدخول وامتلاك صلاحية إدارة المنتجات.

**بيانات المتجر:** تتضمن بنية المشروع بيانات المنتجات وتصنيفاتها وعلاماتها التجارية وصورها ومتغيراتها، إضافة إلى المستخدمين والعناوين وسلة التسوق والطلبات والمدفوعات والشحنات والمرتجعات والكوبونات والمستودعات وحركات المخزون. وجود هذه النماذج في قاعدة البيانات لا يعني بالضرورة تفعيل تكاملات خارجية للدفع أو الشحن.

## التقنيات المستخدمة

- PHP 8.2 أو أحدث.
- Laravel 12.
- قوالب Blade وملفات CSS وJavaScript.
- Vite وNPM لإدارة أصول الواجهة.
- SQLite كقاعدة بيانات افتراضية، مع إمكانية ضبط اتصال قاعدة البيانات من ملف البيئة.
- PHPUnit لاختبار التطبيق.

## متطلبات التشغيل

يتطلب تشغيل المشروع PHP 8.2 أو أحدث، وComposer، وNode.js مع NPM، بالإضافة إلى إعداد قاعدة البيانات وملف البيئة.

## تشغيل المشروع محليًا

من مجلد المشروع، نفّذ الأوامر التالية:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm ci
npm run build
php artisan storage:link
php artisan serve
