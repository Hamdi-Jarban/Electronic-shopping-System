# نظام التسوق الإلكتروني

**وصف المشروع**

نظام التسوق الإلكتروني هو تطبيق ويب مبني باستخدام Laravel، يتيح للزوار استعراض المنتجات والاطلاع على تفاصيلها، كما يوفّر للعميل إمكانية إضافة المنتجات إلى سلة التسوق وإتمام الطلب. ويضم النظام لوحة إدارة لإدارة المنتجات، محمية بتسجيل الدخول والصلاحيات.

> **حالة المشروع:** المشروع حاليًا في مرحلة التطوير، وقد تتغير وظائفه أو تُضاف إليه ميزات جديدة مع استمرار العمل عليه.

## أهداف المشروع

يهدف المشروع إلى بناء منصة تجارة إلكترونية متكاملة تساعد على نقل تجربة التسوق التقليدية إلى بيئة رقمية سهلة وآمنة، وتوفر أساسًا قابلًا للتوسع لخدمة العملاء وإدارة العمليات التجارية من مكان واحد. وما زال المشروع في مرحلة التطوير، لذلك ستتوسع أهدافه ووظائفه تدريجيًا.

- **تقديم تجربة تسوق رقمية متكاملة** تتيح للعملاء اكتشاف المنتجات، والاطلاع على تفاصيلها، وإضافتها إلى سلة التسوق، وإرسال طلباتهم بسهولة.
- **تطوير منصة قابلة للنمو والتوسع** لتستوعب زيادة أعداد المنتجات والعملاء والطلبات، مع إمكانية إضافة خدمات وخصائص جديدة مستقبلًا.
- **تمكين إدارة المتجر إلكترونيًا** من خلال أدوات تساعد على تنظيم المنتجات والتصنيفات والعلامات التجارية ومتابعة الطلبات والمخزون.
- **تحسين تجربة العملاء** عبر واجهة واضحة وسهلة الاستخدام، وتوفير رحلة تسوق منظمة من استعراض المنتجات إلى إتمام الطلب.
- **دعم كفاءة العمليات التجارية** من خلال تنظيم بيانات المنتجات والعملاء والطلبات والمخزون ضمن نظام موحد.
- **تعزيز موثوقية النظام وأمانه** عبر تنظيم صلاحيات المستخدمين وحماية وظائف الإدارة والبيانات.
- **تهيئة المشروع للتطوير المستقبلي** بما يسمح بإضافة إمكانات مثل وسائل الدفع الإلكتروني، وخيارات الشحن، والعروض والخصومات، والتقارير، وفقًا لاحتياجات المشروع.
- **توفير أساس تقني مرن** يمكن تطويره وصيانته باستخدام تقنيات ويب حديثة، مع قابلية تكييفه لاحتياجات المتجر وتوسّع نطاقه.


## الوظائف الرئيسية

**واجهة العميل:** عرض المنتجات وتفاصيلها، وإدارة سلة التسوق، وإتمام الطلب، بالإضافة إلى وظائف التسجيل وتسجيل الدخول وإدارة الملف الشخصي.

**لوحة الإدارة:** عرض المنتجات وإضافة منتجات جديدة. يتطلب الوصول إلى لوحة الإدارة تسجيل الدخول وامتلاك صلاحية إدارة المنتجات.

**بيانات المتجر:** تتضمن بنية المشروع بيانات المنتجات وتصنيفاتها وعلاماتها التجارية وصورها ومتغيراتها، إضافة إلى المستخدمين والعناوين وسلة التسوق والطلبات والمدفوعات والشحنات والمرتجعات والكوبونات والمستودعات وحركات المخزون. وجود هذه النماذج في قاعدة البيانات لا يعني بالضرورة تفعيل تكاملات خارجية للدفع أو الشحن.

## التقنيات المستخدمة

- PHP 8.2 أو أحدث.
- Laravel 12.
- قوالب Blade وملفات CSS وJavaScript.
- Vite وNPM لإدارة أصول الواجهة.
- SQLite كقاعدة بيانات افتراضية، مع إمكانية ضبط اتصال قاعدة البيانات من ملف البيئة.
- PHPUnit لاختبار التطبيق.

## متطلبات التشغيل

يتطلب تشغيل المشروع PHP 8.2 أو أحدث، وComposer، وNode.js مع NPM، بالإضافة إلى إعداد قاعدة البيانات وملف البيئة.

## تشغيل المشروع محليًا

من مجلد المشروع، نفّذ الأوامر التالية:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
npm ci
npm run build
php artisan storage:link
php artisan serve
